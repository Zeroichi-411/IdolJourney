# IdolJourney

新結成の女性アイドルグループ（1期生20名）のひとりとして、卒業までの日々を生きるブラウザゲームです。

## 遊び方

### いちばん簡単な方法（インストール不要）

`play/IdolJourney.html` をダブルクリックしてブラウザで開くだけで遊べます。

### 開発する場合（Node.js が必要）

```bash
npm install
npm run dev      # 開発サーバー起動 → 表示されたURLをブラウザで開く
npm test         # ゲームロジックのテスト
npm run build    # dist/ に静的ファイルを出力
npm run build:single  # play/IdolJourney.html（1ファイル版）を再生成
```

## ゲームの流れ

- 1ヶ月を **前半・後半** に分け、毎回1つ行動を選びます。
  - ボーカル／ダンス／ビジュアルレッスン（能力アップ・体力消費。疲れているとケガのリスク）
  - 休み（体力回復）
  - 他アイドルと交流（仲良し度アップ。ただし喧嘩して下がることも。人気メンバーと仲が良いほど自分の注目度も上がり、毎ターン「人脈ボーナス」が入る）
  - SNS投稿（ジャンルを選んで投稿。投稿内容とバズ／炎上の理由はランダム。炎上の重さによって謹慎や卒業命令も）
- 約3ターンに1回、**日常イベント**（バラエティのオファー、メンバーとの衝突、握手会など）が起き、選択肢によって結果が変わります。
- **3・6・9・12月** にシングル発売。能力＋注目度＋期の若さ（新しい期ほど運営に推される）で序列が決まり、16名の選抜（1〜3列目）とアンダーに分かれます。序列が高いほど注目度が上がります。
- **2年目以降の8月** は総選挙。注目度がより重視され、1位は次のシングルでセンターを務めます。
- メンバーは年々卒業し、在籍が18人以下になるとオーディションで10名前後の新期生が加入します。
- 3年目からは自分で卒業を発表でき、8年目終了で自動的に卒業。エンディングで経歴と称号が表示されます。
- 進行はブラウザ（localStorage）に自動セーブされます。

## 構成

- `src/game/` … DOM に依存しないゲームロジック（`engine.ts` がターン進行の中心、調整値は `constants.ts`、SNS 投稿の文章データは `snsPosts.ts`）
- `src/ui/` … 画面の描画
- `src/main.ts` … 画面遷移と入力処理
